Bankroll¶

The bankroll object simulates the financial side of simulations. It takes into account things like max drawdown limits and in the future may include risk free rate investments, interest and concepts like that.

Exceptions¶

exception keeks.utils.RuinError[source]

Bases: Exception

Exception raised when a bankroll safeguard refuses a removal.

Raised by the BankRoll class in two cases: a removal would take the funds below zero (bankruptcy), or a removal exceeds the configured max_transaction_loss fraction of current funds. The message names the attempted amount, the configured limit, and the current funds; the simulators re-report it as a UserWarning when a refusal stops a run.

Summarizing a run¶

evaluate_strategy mutates the bankroll and returns nothing, so keeks.metrics.summarize_history() reduces bankroll.history to the numbers that distinguish strategies: bets recorded, total return, geometric growth per bet, maximum drawdown against the running peak, and whether the run ended ruined. Values that cannot be defined (growth with no recorded bets or nonpositive end funds, return from a zero start) are None rather than 0.0; an empty, non-finite or negative history raises ValueError.

from keeks import summarize_history

summary = summarize_history(bankroll.history)
print(summary.max_drawdown, summary.geometric_growth_per_period)

Comparing strategies on a recorded log¶

keeks.comparison.compare_strategies() replays one recorded log through several strategies, each from a fresh strategy and a fresh bankroll, and returns one StrategyComparison per strategy (name plus its HistorySummary), ranked by sort_by with undefined (None) values last.

from keeks import FixedFractionStrategy, KellyCriterion, compare_strategies

odds = {"payoff": 1.0, "loss": 1.0, "transaction_cost_rate": 0.0}
rows = compare_strategies(
    {
        "Kelly": lambda: KellyCriterion(**odds),
        "Fixed 5%": lambda: FixedFractionStrategy(**odds, fraction=0.05),
    },
    probabilities,
    outcomes,
    payoff=1.0,
    loss=1.0,
    fee_per_bet=0.0,
    initial_funds=1000.0,
)
for row in rows:
    print(row.name, row.summary.max_drawdown)
keeks.comparison.compare_strategies(strategies: Mapping[str, Callable[[], BaseStrategy]], probabilities: Sequence[float], outcomes: Sequence[bool | int], *, payoff: float, loss: float, fee_per_bet: float, initial_funds: float, percent_bettable: float = 1.0, max_transaction_loss: float | None = None, sort_by: str = 'geometric_growth_per_period') → tuple[StrategyComparison, ...][source]¶

Replay one recorded bet log through several strategies and rank them.

Each strategy is built by calling its factory and runs against a fresh BankRoll, so no state carries from one run to the next. Replay is by HistoricalBinarySimulator; a strategy whose odds differ from payoff/loss raises its ValueError unchanged. This is an educational look at past data, not advice.

Parameters:

  • strategies (mapping of str to callable) – Strategy name to a zero-argument factory returning a fresh strategy. Must be non-empty.

  • probabilities (sequence) – The recorded log, as for HistoricalBinarySimulator.

  • outcomes (sequence) – The recorded log, as for HistoricalBinarySimulator.

  • payoff (float) – The odds and flat fee passed to the simulator.

  • loss (float) – The odds and flat fee passed to the simulator.

  • fee_per_bet (float) – The odds and flat fee passed to the simulator.

  • initial_funds (float) – Passed to each fresh BankRoll.

  • percent_bettable (float) – Passed to each fresh BankRoll.

  • max_transaction_loss (float) – Passed to each fresh BankRoll.

  • sort_by (str, default="geometric_growth_per_period") – A numeric or boolean HistorySummary field: total_return, geometric_growth_per_period, end, max_drawdown or ruined. max_drawdown and ruined rank smaller first, the rest larger first; None values always rank last, and ties keep the mapping’s order.

Returns:

One row per strategy, best first.

Return type:

tuple of StrategyComparison

Raises:

ValueError – If the arguments are invalid; checked before any strategy runs.

Examples

>>> from keeks import FixedFractionStrategy
>>> odds = {"payoff": 1.0, "loss": 1.0, "transaction_cost_rate": 0.0}
>>> rows = compare_strategies(
...     {
...         "5%": lambda: FixedFractionStrategy(**odds, fraction=0.05),
...         "20%": lambda: FixedFractionStrategy(**odds, fraction=0.2),
...     },
...     [0.6, 0.6, 0.6],
...     [1, 0, 1],
...     payoff=1.0, loss=1.0, fee_per_bet=0.0, initial_funds=100.0,
... )
>>> [(row.name, round(row.summary.end, 2)) for row in rows]
[('20%', 115.2), ('5%', 104.74)]
